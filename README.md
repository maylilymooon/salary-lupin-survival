# 💼 월급루팡 서바이벌

> 퇴근 시간까지 살아남아라.
> 업무는 **적당히**, 멘탈은 **지키고**, 상사 의심도는 **낮게**.

설치 없이 브라우저에서 바로 플레이하는 캐주얼 웹게임입니다.
HTML/CSS/JavaScript 파일 하나(`index.html`)로 동작합니다.

### ▶ [지금 플레이하기](https://maylilymooon.github.io/salary-lupin-survival/)

---

## 🎮 게임 소개

플레이어는 (주)무한성장의 회사원 김대리입니다.
점심을 먹고 돌아온 **오후 1시**부터 **오후 6시** 퇴근까지 회사에서 버텨야 합니다.

일만 하면 멘탈이 무너지고, 몰래 딴짓을 하면 멘탈은 회복되지만 팀장님의 의심을 삽니다.
업무 진행도를 적당히 채우면서 멘탈을 지키고, 들키지 않고 퇴근하는 것이 목표입니다.

## 📊 상태

| 상태 | 범위 | 설명 |
|---|---|---|
| 🕐 현재 시간 | 오후 1:00 → 퇴근 | 실제 시간이 아니라 **행동할 때마다** 흐릅니다 |
| 🏁 퇴근 시간 | 기본 오후 6:00 | 이벤트로 당겨지거나 늦춰집니다 |
| 📊 업무 진행도 | 0 ~ 100 | 퇴근 때 최소 50%는 채워야 합니다 |
| 🧠 멘탈 | 0 ~ 100 | 0이 되면 즉시 번아웃 엔딩 |
| 👀 상사 의심도 | 0 ~ 100 | 100이 되면 즉시 적발 엔딩 |

## 🕹️ 행동

| 키 | 행동 | 효과 | 소요 시간 |
|---|---|---|---|
| `1` | 💻 업무하기 | 업무 ▲ · 멘탈 ▼ · 의심 ▼ | 20분 |
| `2` | 📱 몰래 웹툰 보기 | 멘탈 ▲▲ · 의심 ▲ | 20분 |
| `3` | ☕ 커피 타러 가기 | 멘탈 ▴ · 의심 ▾ | 10분 |
| `4` | 🚽 화장실로 도피 | 멘탈 ▲ · **자주 가면 의심 ▲▲** | 15분 |
| `5` | 🖥️ 업무하는 척하기 | 업무 ▴ · 의심 ▼▼ | 15분 |

- 화장실은 최근 90분 안에 간 횟수에 따라 의심도가 `+2 → +10 → +22 → +35`로 크게 오릅니다.
- 웹툰·커피·화장실·업무하는 척하기는 **월급루팡 횟수**로 집계됩니다.

## 🚨 상사 시스템

가끔 화면 위에 **"🚨 팀장님 접근 중!"** 경고가 나타납니다.

- **3초 안에** `Alt+Tab! 업무 화면으로 전환` 버튼을 누르거나 `Space` 키를 누르면 위기를 피합니다.
- 못 피하면 그때 하던 행동에 따라 결과가 달라집니다.
  - 업무 중이거나 업무하는 척 중: 오히려 의심도가 내려갑니다.
  - 화장실: 빈자리를 들켜 의심도가 오릅니다.
  - 웹툰·커피: **현재 의심도에 비례한 확률로 적발**됩니다. 웹툰을 보던 중이면 확률이 더 높습니다.
- 적발되면 `팀장님: "지금 뭐 하고 있었어요?"` 팝업과 함께 **멘탈 -15, 의심도 +20** 패널티를 받습니다.
- 팀장님은 행동할 때뿐 아니라 가만히 있을 때도 불시에 나타납니다. 의심도가 높을수록 더 자주 옵니다.

## 🎲 랜덤 이벤트

행동할 때마다 약 33% 확률로 이벤트가 발생합니다. 좋은 이벤트와 나쁜 이벤트가 섞여 있습니다.

| 이벤트 | 효과 |
|---|---|
| ⚠️ 팀장님이 자리에서 일어났습니다. | 의심 +3, 높은 확률로 팀장님 접근 |
| 😱 팀장님이 갑자기 뒤에서 나타났습니다! | 하던 행동에 따라 칭찬받거나 크게 의심받음 |
| 📢 갑작스러운 회의가 잡혔습니다. | 시간 +30분, 멘탈 ▼ ("결론: 다음 주에 다시 논의") |
| 💬 옆자리 직원이 말을 걸어옵니다. | 시간 +15분, 멘탈 ▴ |
| 🍪 누가 간식을 돌렸습니다. | 멘탈 +10 |
| 🎉 대표님이 오늘 30분 일찍 퇴근하라고 합니다! | 퇴근 -30분, 멘탈 +15 |
| 📨 퇴근 10분 전에 업무 요청이 왔습니다. | 퇴근 +30분, 멘탈 -15 (퇴근이 가까울 때만 발생) |
| 🖨️ 프린터가 또 용지 걸림입니다. | 시간 +10분, 멘탈 ▼ |
| 📧 전체 메일에 "확인했습니다" 답장 47개 | 멘탈 ▼ |
| 🔄 Windows 강제 업데이트 | 시간 +15분, 멘탈 ▲, 의심 ▼ |
| 🍻 팀 단톡방 회식 공지 — "자율 (필참)" | 멘탈 -12 |
| ☕ 팀장님이 커피를 쏘셨습니다. | 멘탈 ▲, 의심 -8 |
| 💡 VLOOKUP이 한 번에 성공! | 업무 +10, 멘탈 ▲ |
| 💥 저장 안 한 엑셀이 "응답 없음" | 업무 -10, 멘탈 -10 |
| 🎂 탕비실에 생일 케이크 등장 | 멘탈 +8, 시간 +10분 |
| 📋 인사팀 PC 사용 기록 점검 예정 | 의심 +10, 멘탈 ▼ |
| 📶 사내 와이파이 끊김 | 시간 +10분, 의심 ▼ |

## 🏁 엔딩

퇴근 시간이 되거나 멘탈·의심도가 한계에 도달하면 게임이 끝나고, 플레이 방식에 따라 엔딩이 갈립니다.
위에서부터 순서대로 조건을 확인합니다.

| 엔딩 | 조건 | 한 줄 평 |
|---|---|---|
| 🚨 월급루팡 적발 | 의심도 90 이상 또는 적발 3회 이상 | "팀장님은 당신의 Alt+Tab 속도보다 빨랐다." |
| 😵 번아웃 엔딩 | 멘탈 10 이하 | "업무 진행도 N%. 멘탈 N%. 우리는 이것을 성공이라고 부를 수 있을까?" |
| 💀 야근 확정 | 업무 진행도 50% 미만 | "퇴근은 존재하지 않았다." |
| 🏆 S급 월급루팡 | 업무 70%↑, 멘탈 50↑, 루팡 6회↑, 의심도 50 미만, 적발 0회 | "일도 했고 놀기도 했다. 아무도 당신이 놀았다는 사실을 모른다." |
| 🤖 모범 사원 | 업무 90%↑, 루팡 2회 이하 | "회사는 당신의 헌신을 기억하지 않는다. 하지만 연말 평가는... 아마도?" |
| 😎 프로 직장인 | 업무 70%↑ | "할 일은 했다. 그 이상은 회사 욕심이다." |
| 🐢 아슬아슬 생존 | 그 외 | "할 건 했다고 우길 수 있는 수준. 나머지는 내일의 내가 하겠지." |

결과 화면에는 **업무 진행도 / 남은 멘탈 / 상사 의심도 / 월급루팡 횟수 / Alt+Tab 성공 / 적발 횟수**가 표시되고,
**다시 출근하기** 버튼으로 재시작할 수 있습니다.

## ⌨️ 조작법

| 키 | 동작 |
|---|---|
| `1` ~ `5` | 행동 선택 (버튼 클릭도 가능) |
| `Space` | Alt+Tab, 팀장님 접근 시 위기 회피 |
| `Enter` | 팝업 확인 / 출근하기 / 다시 출근하기 |

> PC 브라우저에 맞춰 만들었습니다. 좁은 화면에서는 레이아웃이 세로로 쌓입니다.

## ✨ 연출

- 행동에 따라 모니터 화면이 엑셀, 웹툰, 탕비실, 화장실로 바뀝니다. Alt+Tab 할 때는 화면이 번쩍입니다.
- 게이지와 숫자가 부드럽게 움직이고, 값이 바뀌면 `+12`, `-8` 같은 숫자가 떠오릅니다.
- 의심도가 70 이상이거나 멘탈이 20 이하면 화면 가장자리가 빨갛게 깜빡입니다.
- 팀장님에게 적발되면 화면이 흔들립니다.
- 오른쪽 **사내 메신저 로그**에 모든 행동과 이벤트가 시간순으로 쌓입니다.
